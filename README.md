# aimili-vpngate
aimili-vpngate是一个借助vpngate.net让Linux用干净ip出站的代理工具。<br>

上游仓库地址：https://github.com/baoweise-bot/aimili-vpngate<br>

本仓库fork后自定义修改成自己可以使用的工具，支持singbox脚本运行的vps环境，支持绑定域名，支持ip断线后从备选池切换ip。<br>

支持登录失败5次，锁定IP和用户名，锁定后可以通过VPS的重启服务刷新，其余安全加固。<br>

======================以上所有修改均来自于谷歌的 “Gemini”  ======================
